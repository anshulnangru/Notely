# Antigravity — Project Summary

> A full-stack **Notion-clone** built with FastAPI + React (Vite).

---

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | FastAPI, SQLAlchemy, SQLite, JWT |
| Frontend | React, Vite, Zustand, React Router |
| File Storage | Local disk (`/uploads/`) served statically |

---

## ✅ Implemented Features

### 🔐 Authentication
- User registration & login with JWT
- Protected routes (redirect to `/login` if unauthenticated)

### 📄 Pages & Editor
- Hierarchical page tree (nested parent/child pages)
- Page metadata: title, emoji, cover image, favorites, soft-delete (trash)
- **Block-based editor** supporting:
  - Text, H1/H2/H3, Bullet & Numbered lists, Toggle, Quote, Callout
  - Code blocks, Dividers, To-do (checkboxes), Image blocks
- Slash menu (`/`) to insert blocks
- Turn Into menu to convert block types
- Block context menu (right-click actions)
- Editable page header with emoji picker

### ✅ Tasks
- Status: `todo` → `in_progress` → `done`
- Priority: `low`, `medium`, `high`, `urgent`
- Due dates, task assignment to users, subtasks
- **Kanban board view** and **List view**
- Full-detail Task modal

### 🏷️ Tags
- Colored tags applicable to pages and tasks

### 💬 Comments
- Comment threads on pages and tasks ([CommentThread.jsx](file:///Users/irritatednishantgmail.com/Desktop/antigravity/frontend/src/components/Comments/CommentThread.jsx))

### 🔔 Notifications
- Notification bell with unread badge
- Types: `mention`, `comment`, `task_assigned`, `due_soon`

### 📊 Dashboard
- Overview dashboard at `/dashboard`

### 📅 Calendar
- Calendar view at `/calendar`

### 📁 File Uploads
- Local file upload API (`/uploads/`)
- In-editor image upload panel ([FileUploadPanel.jsx](file:///Users/irritatednishantgmail.com/Desktop/antigravity/frontend/src/components/Editor/FileUploadPanel.jsx))
- Files served statically

### 📋 Activity Log
- Backend logs create/update/delete/complete actions on pages, tasks, and comments

### 🌗 Dark / Light Mode
- Theme persisted in `localStorage`, toggled via `data-theme` attribute

---

## ❌ Missing / Incomplete Features

| Area | What's Missing |
|---|---|
| **Real-time collaboration** | No WebSocket support; no simultaneous multi-user editing |
| **@mentions** | Comment model exists but mention parsing & notification wiring not implemented |
| **Activity Log UI** | Backend exists; no frontend component to display the feed |
| **Attachments UI** | Model + upload backend exist; no UI to attach/view files on pages or tasks |
| **Global Search** | No search across pages or block content |
| **Page Sharing / Permissions** | All pages are owner-only; no sharing with other users |
| **PostgreSQL** | Still on SQLite; DB migration to PostgreSQL was planned but not confirmed complete |
| **Notification actions** | Bell shows count; click-through / mark-all-read UI may be incomplete |
| **Comments UI integration** | [CommentThread.jsx](file:///Users/irritatednishantgmail.com/Desktop/antigravity/frontend/src/components/Comments/CommentThread.jsx) exists but may not be rendered inside editor or task views |
| **Mobile Responsiveness** | Layout is desktop-only |
